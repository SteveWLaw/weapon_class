Detailed Description

Represents a weapon sprite with rendering, rotation, and collision detection.

The Weapon class handles sprite rendering from a shared texture atlas, supports multiple attack patterns, and provides collision detection with rotation support. Weapons do not own their texture and are designed for efficient reuse.
